# SOL SCAN

Sol Scan lets you fetch all you tokens on mainnet, sol balance and recent transactions.

## Steps to Start

1. Clone the repo locally 
```bash
git clone <repo_url>
```

2. install dependencies
```bash
npm install
```

3. run the project
```node
npx expo start
```

4. open expo go app on your mobile and scan the qrcode to run the project locallly.
